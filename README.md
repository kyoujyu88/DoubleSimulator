# 🌰 まんじゅう倍々シミュレーター

「5分ごとに2倍に増え続ける栗まんじゅうがあったら？」——そんな思考実験を
3Dと物理演算で体感できるブラウザアプリです。倍々に増え続けるまんじゅうの山を眺めながら、
指数関数的増加（倍々ゲーム）の恐ろしさを目で見て実感できます。

![Three.js](https://img.shields.io/badge/Three.js-r165-049EF4) ![Rapier](https://img.shields.io/badge/Physics-Rapier-orange) ![No Build](https://img.shields.io/badge/build-不要-success)

## 遊び方

`index.html` をブラウザで開くだけです（ビルド・サーバー不要。Three.js はCDNから読み込むためネット接続のみ必要）。

```bash
# そのまま開く
open index.html        # macOS
start index.html       # Windows

# またはローカルサーバーで
npx serve .
python3 -m http.server
```

GitHub Pages にデプロイすればURLを共有するだけで誰でも遊べます。

## 機能

- **本物の物理演算** — Rust製物理エンジン [Rapier](https://rapier.rs)（WASM）で1個1個が剛体。
  倍増のたびに既存のまんじゅうの上に分身が生まれ、転がり落ちて自然な山を作る
- **正確な個数表示** — BigInt で計算し、万・億・兆…**無量大数**(10⁶⁸) まで漢数字表記
- **体積・質量の比較** — お茶碗 → お風呂 → 教室 → 東京ドーム → 富士山 → 月 → 地球 → 太陽
- **マイルストーン通知** — 「部屋が埋まりました！」「地球がまんじゅうで埋め尽くされました！」
- **経過時間表示** — 1回=5分換算で「現実なら何時間後か」を表示
- **倍増間隔スライダー** — 0.5〜10秒で調整可能
- **🚀 宇宙へ捨てるボタン** — 全まんじゅうに打ち上げの力がかかり、空高く飛んでいく。
  …でも宇宙のどこかで増え続けています（天体サイズになってからでは手遅れです）

## ステージ進行（インクリメンタルゲーム風）

増え続けるまんじゅうは、量に応じて姿を変えていきます。

| ステージ | 条件 | 見どころ |
|---|---|---|
| ⚙️ 物理の山 | 〜4,096個 | 1個1個が剛体として転がり積もる |
| 🗻 巨大な山 | 〜10¹² m³ | 山ごとスケールアップ、カメラが引いていく |
| 🪐 まんじゅう惑星 | 半径6km〜 | 体積から計算した実寸のまんじゅう球が、フォボス→ケレス→月→地球→木星→太陽→シリウス→アークトゥルス→ベテルギウスと**実寸比で並んで比較**される。追い抜くたびに「◯◯を超えました！」 |
| ☀️ まんじゅう恒星 | 質量0.08太陽質量〜 | 恒星の点火限界を超え、まんじゅうが自ら輝き始める |
| 🕳 まんじゅうブラックホール | 倍増132回目〜 | 自身のシュヴァルツシルト半径を超えて重力崩壊。降着円盤つき。これは演出ではなく**本当に計算上そうなります**（作中時間でたった11時間後！） |

## 技術メモ

- 物理剛体は既定で4,096個まで（URLに `?phys=8192` を付けると変更可、128〜8,192）。
  それを超えると全ボディを固定し、個数の3乗根に比例して**山ごとスケールアップ**＋
  カメラが自動で引いていくことで、指数爆発を破綻なく表現しています
- まんじゅうのコライダーは `roundCylinder`（押しつぶした円盤＋丸い縁）で、
  本物のまんじゅうらしい転がり方・積もり方をします
- 描画は Three.js の `InstancedMesh` で一括描画（ドローコール1回）
- 巨大スケールでも破綻しないよう logarithmic depth buffer と動的 far plane を使用

### パフォーマンス最適化

- **石化（petrification）** — 3秒以上静止した剛体は固定ボディに変換し、物理ソルバーから
  外します。山の内部・下層のまんじゅうは二度と動かないため、実際に計算されるのは
  表面で転がっている層だけです（HUDの「剛体 / FPS」で可動数を確認できます）
- **描画行列の更新スキップ** — 静止した剛体は `InstancedMesh` の行列書き込みも省略
- **描画LOD** — 個数に応じてまんじゅうのポリゴン数を3段階で自動削減
  （〜512個: 24×18分割 / 〜2,048個: 14×10 / それ以上: 8×6）。
  なお衝突判定は解析形状なのでポリゴン数と物理コストは無関係です

## 豆知識

栗まんじゅう1個を約80cm³とすると、5分ごとに倍増した場合——

| 経過時間 | 個数 | だいたいの量 |
|---|---|---|
| 1時間 | 4,096個 | お風呂いっぱい |
| 3時間 | 約687億個 | 東京ドーム4個分 |
| 5時間 | 約1.15×10¹⁸個 | 富士山230個分 |
| **約7時間** | 約1.4×10²⁵個 | **地球が埋まる** |

たった7時間で地球が終わります。ロケットで捨てたくなる気持ちがわかりますね。
