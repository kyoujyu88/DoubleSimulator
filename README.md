# 🌰 バイバイン シミュレーター

ドラえもんのひみつ道具「バイバイン」を3Dで体感できるブラウザアプリです。
一滴かけられた栗まんじゅうが5分（シミュレーターでは数秒）ごとに**2倍**に増え続け、
指数関数的増加（倍々ゲーム）の恐ろしさを目で見て実感できます。

![Three.js](https://img.shields.io/badge/Three.js-r165-049EF4) ![No Build](https://img.shields.io/badge/build-不要-success)

## 遊び方

`index.html` をブラウザで開くだけです（ビルド・サーバー不要。Three.js はCDNから読み込むためネット接続のみ必要）。

```bash
# そのまま開く
open index.html        # macOS
start index.html       # Windows

# またはローカルサーバーで
npx serve .
python3 -m http.server
```

GitHub Pages にデプロイすればURLを共有するだけで誰でも遊べます。

## 機能

- **3D栗まんじゅう** — 一定間隔で倍々に増殖。新しいまんじゅうは「ぽよん」と出現
- **正確な個数表示** — BigInt で計算し、万・億・兆…**無量大数**(10⁶⁸) まで漢数字表記
- **体積・質量の比較** — お茶碗 → お風呂 → 教室 → 東京ドーム → 富士山 → 月 → 地球 → 太陽
- **マイルストーン通知** — 「部屋が埋まりました！」「地球がまんじゅうで埋め尽くされました！」
- **作中経過時間** — 原作どおり1回=5分換算で何時間後かを表示
- **倍増間隔スライダー** — 0.5〜10秒で調整可能
- **🚀 宇宙へ捨てるボタン** — 原作の結末を再現。…でも宇宙のどこかで増え続けています

## 技術メモ

- Three.js の `InstancedMesh` で最大8,192個を個別描画。それを超えると
  個数の3乗根に比例して**山ごとスケールアップ**し、カメラが自動で引いていくことで
  指数爆発を破綻なく表現しています
- まんじゅうの配置は決定論的なハッシュで「内側から外殻へ」詰めるため、
  既存のまんじゅうが動かずに山が成長します
- 巨大スケールでも破綻しないよう logarithmic depth buffer と動的 far plane を使用

## 豆知識

栗まんじゅう1個を約80cm³とすると、5分ごとに倍増した場合——

| 経過時間 | 個数 | だいたいの量 |
|---|---|---|
| 1時間 | 4,096個 | お風呂いっぱい |
| 3時間 | 約687億個 | 東京ドーム4個分 |
| 5時間 | 約1.15×10¹⁸個 | 富士山230個分 |
| **約7時間** | 約1.4×10²⁵個 | **地球が埋まる** |

たった7時間で地球が終わります。ロケットで捨てたくなる気持ちがわかりますね。
